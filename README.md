# 华伴 V1.1 New

定位：AI 原生的华人本地通讯与内容网络。

内部理解：华伴采众人之长，补用户之需。该句只作为产品设计判断，不作为对外宣传文案。

对外表达：华伴是一款内置 AI 的 App，帮助用户从海量信息中挣脱，重新专注自己的本地生活。

微信和小红书更与国内内容、关系和平台生态相关；华伴要与本地相连、与世界相通。

## 主线

```text
附近动态
→ 作者名片
→ 添加好友 / 关注 / 收藏 / 备注
→ 聊天
→ AI 推荐更多本地人与内容
```

## 第一阶段范围

- 本地城市内容流
- 作者名片与我的二维码名片
- 好友关系、备注、标签与来源
- 好友聊天与未读消息
- AI 整理配文、搜索附近内容、推荐名片

第一阶段不做需求卡、订单、合约、临时交易会话和重交易平台。

## 目录

- `app/`：用户端移动 Web 原型
- `official/`：官网设计稿和公开表达入口
- `admin/`：后台运营控制台、审核、积分、官网、n8n 工作流
- `api/`：API contract 与后续服务代码
- `db/`：数据库 schema 与迁移说明
- `docs/`：产品范围、系统重建方案、数据字典
- `n8n/`：自动化工作流设计
- `workflows/`：运营与工程流程说明

## 三端设计入口

- 用户端：`http://localhost:5177/app/`
- 官网：`http://localhost:5177/official/`
- 后台：`http://localhost:5177/admin/`

## 本地预览

```bash
npm run dev
```

然后打开 `http://localhost:5177/app/`。
