# 华伴 V1.1 功能闭环台账

更新日期：2026-07-28

本文件用于区分“页面做了”和“功能真正闭环”。以后任何功能都不能只按按钮存在或页面能打开来判断完成，必须按本台账逐项验收。

## 闭环等级

| 等级 | 状态 | 判定标准 |
| --- | --- | --- |
| L0 | 未做 | 没有入口、页面或接口。 |
| L1 | 页面存在 | 有入口和页面，但不保证可交互。 |
| L2 | 前端交互可用 | 用户能在浏览器内完成本地交互，例如选择、预览、编辑、保存本地状态。 |
| L3 | 本地接口闭环 | 本地 dev server/API 能写入或返回真实结构化结果。 |
| L4 | 线上接口闭环 | Vercel 线上环境能完成接口链路，失败时有明确错误。 |
| L5 | 真实设备通过 | 手机实测通过，包含权限、文件选择、网络、返回、刷新和异常路径。 |

## 验收原则

- 按钮能点不等于完成。
- 页面出现不等于功能可用。
- 前端本地保存不等于后端持久化。
- 本地接口通过不等于线上通过。
- AI 有按钮不等于 AI 真参与。
- 积分、推荐、身份码、发布、审核、支付、外部 API 授权必须有确定数据记录。
- 高风险动作必须可撤销、可审计、可失败，不允许假成功。

## 核心链路 1：发布动态

目标链路：

```text
底部动态图标 → 动态页 → 右上角 + → 选择来源 → 打开系统相册/相机/文件 → 预览 → 编辑配文 → AI 整理 → 调整图片顺序 → 设置可见范围 → 草稿 → 发布 → 动态列表出现 → 积分/审核记录
```

| 环节 | 当前等级 | 当前状态 | 验收方法 | 阻塞/风险 | 下一步 |
| --- | --- | --- | --- | --- | --- |
| 动态页右上角 `+` 打开来源菜单 | L5 待用户确认 | 发布入口已从底部导航移到动态页右上角：从相册选择、拍摄、写文字、文件。 | 手机 Safari/浏览器先点底部动态图标进入动态页，再点右上角 `+`，确认菜单出现。 | 浏览器自带 `+` 不应再和华伴发布入口混淆。 | 用户实测。 |
| 相册选择 | L5 待用户确认 | 使用 `<input type=file accept=image/* multiple>`，系统已能弹出照片库。 | 选择 1-6 张小图，确认返回编辑页并显示主图与缩略图。 | iOS 浏览器对文件权限、刷新恢复有限制。 | 用户实测；失败则改为显式“选择照片”按钮。 |
| 拍摄 | L5 待用户确认 | 使用 `capture=environment` 调起系统拍摄入口。 | 点拍摄，确认能打开相机或系统拍摄选项。 | 部分浏览器不强制打开相机，只显示系统选择菜单。 | 如不稳定，增加说明和拍摄回退入口。 |
| 文件选择 | L5 待用户确认 | 使用普通文件输入。 | 选任意小文件，确认文件名预览出现。 | 文件只做本地预览，尚未上传对象存储。 | 接对象存储前标为前端可用。 |
| 媒体预览 | L2 | 图片/视频/文件可本地预览。 | 选择媒体后查看主预览、缩略图、页码。 | 刷新后真实文件不会长期恢复。 | 对接对象存储后升 L4。 |
| 图片顺序调整 | L2/L5 待手机确认 | 小图点击后显示绿色选中框，拖拽小图调整顺序。 | 选第 2 张小图，确认绿框出现；拖到第 1 张位置，确认主图和缩略图顺序变化。 | 手机浏览器拖拽手感需真实设备确认。 | 如手机拖拽不稳定，再补长按排序页。 |
| 删除图片 | L2 | 缩略图 `×` 可删除当前图片。 | 选多图后删除一张，确认数量变化。 | 删除后草稿只保存结构，不保存文件本体。 | 对接对象存储后持久化。 |
| 配文编辑 | L2 | 文本框可输入，输入自动保存草稿。 | 输入文字，退出保存，再继续草稿。 | 仅 localStorage。 | 接后端草稿表后升 L4。 |
| AI 整理 | L3/L4 待线上实测 | 调用 `/api/v1/ai/compose-post`，失败明确提示。 | 输入一句话点 AI 整理，确认配文被替换或提示失败。 | 依赖线上 AI key 和接口。 | 用线上实测判定 L4。 |
| 可见范围 | L2 | 可选当地、好友、公开、仅自己，并进入发布请求 body。 | 点可见范围，选择好友可见，确认显示变化。 | 后端是否使用 visibility 尚未确认。 | API 存储/动态展示过滤后升 L4。 |
| 草稿 | L2 | 自动保存；重新点 `+` 时提示继续草稿/新建；返回时提示保存/放弃/继续。 | 输入文字退出，选择继续草稿；再新建确认旧草稿清掉。 | 网页端不能长期保存真实文件本体。 | 后端草稿表和媒体上传后升 L4。 |
| 发布 | L3/L4 待线上实测 | 点击右上 `✓` 调 `/api/v1/dynamics`，成功后动态列表新增，失败不清草稿。 | 选图/写字后发布，确认动态页出现新内容。 | 线上 API、数据持久化和媒体上传尚需确认。 | 用户实测；必要时写自动化用例。 |
| 积分/审核 | L1 | 发布成功后目前触发前端礼花和 `loadGrowth`，但未确认真实积分入账。 | 查积分流水/后台审核记录。 | 不能把礼花当入账。 | 接真实 points ledger 和审核记录后再验收。 |

## 当前结论

发布动态链路当前不能标记为“完成”。它只能标记为：

```text
前端发布器 L2 已增强，线上是否达到 L5 需要手机实测；后端发布、媒体上传、积分入账、审核仍未完整闭环。
```

## 后续新增台账项

优先顺序：

1. 身份码唯一性、手机号更换、二维码/分享链接一致性。
2. 推荐关系与一级/二级积分入账。
3. 新手任务提示词奖励。
4. 添加朋友、通讯录、备注、标签、推荐给朋友。
5. 地图位置、Google 地址确认、导航入口。
6. 内容安全审核：成人/儿童展示区别、遮挡、成年证明。
7. n8n 5 Agent 场景模拟与失败日志。
8. 官网招募、下载入口、身份权重展示。
