# 微信式页面参考映射

华伴 V1.1 参考微信的使用习惯，但不复制微信视觉与品牌。目标是让华人用户一打开就知道怎么用。

## 底部主入口

底部主导航参考小红书的使用习惯：`首页 / 市集 / + / 消息 / 我`。中间红色 `+` 是发布功能，不作为普通页面。

| 参考习惯 | 华伴 V1.1 页面 | 第一阶段功能 |
| --- | --- | --- |
| 小红书首页 | 首页 / 动态 | 统一动态信息流、附近内容、城市推荐 |
| 小红书市集 | 市集 | 本地服务、二手好物、活动票券 |
| 小红书发布 `+` | 发布动态 | 从相册选择、拍摄、写文字 |
| 小红书消息 | 消息 | 好友聊天、未读、系统通知、AI 助手会话 |
| 小红书我的 | 我的 | 个人资料、二维码名片、积分权益、设置 |

通讯录保留在左侧抽拉菜单，承接微信式好友管理习惯。

微信右上角 `+` 的快捷能力，在华伴中放到左上角抽拉菜单：

- 发起群聊
- 添加朋友
- 扫一扫
- 收付款

## 常用二级页

- 聊天详情：文字、语音入口、未读、已读状态。
- 个人资料页：头像、昵称、城市、身份码、来源。
- 名片页：二维码名片、添加好友、备注、标签。
- 发布页：图文发布、AI 整理配文、预览确认。
- 动态详情页：参考小红书式图文流，包含动态详情、点赞、关注、收藏、评论入口。
- 我的二维码：分享名片、扫码添加。
- 设置页：账号、安全、隐私、通知、语言。

## 华伴差异

- 首页保留 AI 智能助手，而不是直接进入消息列表。
- “动态”优先承载本地城市内容，而不是泛娱乐平台。
- 微信式搜索和小红书式搜索都改为 AI 搜索：用户用语音或文字说目标，AI 决定搜索动态、市集、名片、联系人或执行匹配。
- 关系沉淀必须记录来源、标签和备注。
- AI 输入栏是全局入口，可以打开发布、搜索附近内容、推荐名片和进入聊天。
