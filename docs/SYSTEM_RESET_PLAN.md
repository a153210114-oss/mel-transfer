# 华伴 V1.1 系统级重建方案

## 原则

华伴 V1.1 是新项目，不在旧交易主线里继续修补。

旧项目只保留可复用资产：

- 页面风格
- 验证码与身份码经验
- 附近动态 API 经验
- 好友关系 API 经验
- 积分账本经验
- AI Prompt 与自动化经验

旧项目不继承：

- 需求卡片
- 重交易
- 订单确认
- 合约履约
- 临时交易会话
- 供需撮合主线

## 新系统范围

```text
用户端
├─ AI 首页
├─ 附近动态
├─ 发布动态
├─ 作者名片
├─ 我的二维码名片
├─ 好友列表
├─ 好友资料
├─ 好友备注
├─ 好友聊天
└─ 积分权益

后台
├─ 用户管理
├─ 动态管理
├─ 名片关系管理
├─ 城市内容管理
├─ AI Prompt 管理
├─ 自动化任务管理
└─ 数据统计

自动化
├─ 新用户注册欢迎
├─ 发动态 AI 整理
├─ 城市内容标签
├─ 名片推荐
├─ 好友关系沉淀
└─ 城市运营日报
```
