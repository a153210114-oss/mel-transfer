# 华伴 AI 功能插件与收费机制

更新日期：2026-07-28

本文件定义华伴未来可收费的 AI 功能插件与分档订阅体系。当前 V1.1 先做产品和数据预留，不接真实支付。

## 1. 基本判断

华伴的 AI 能力分为基础能力、增强执行能力、生成能力、自动化能力和商家/API 能力。

基础能力用于让用户顺畅使用华伴；增强执行、内容生成、经营小店、配置自动化和处理复杂任务，未来可以按订阅档位和插件额度收费。

收费不改变合规边界：

- 付费用户也不能绕过内容审核。
- 付费用户也不能绕过外部 API 授权。
- 付费用户也不能获得积分固定收益承诺。
- 付费插件只购买功能能力、额度或服务效率，不购买平台收益权。

## 2. 订阅分档

订阅按“AI 能执行到哪一步”分档，而不是简单按页面收费。

| 档位 | 面向用户 | AI 执行能力 | 插件与额度 |
| --- | --- | --- | --- |
| `free` 基础版 | 普通用户 | AI 对话、打开页面、基础搜索、简单动态草稿 | 免费基础额度 |
| `plus` 增强版 | 高频个人用户 | 多步骤语义执行、连续语音修改、关系/动态摘要 | 语音操控增强、文案增强基础额度 |
| `creator` 创作版 | 内容发布者、活动组织者 | 图文生成、视频脚本/封面、表单生成、发布前审核 | 图文视频生成、表单插件额度 |
| `business` 商家版 | 小店、服务者 | 服务卡、卡包、优惠券、API 授权、客户线索整理 | 小店 API、表单、自动化额度 |
| `ops` 共创/运营版 | 城市运营、共创成员 | 内容审核辅助、城市内容整理、批量任务、运营报表 | 审核辅助、自动化运行额度 |

分档原则：

- 免费版保证产品可用，不把基础沟通和身份关系变成付费门槛。
- 付费版主要卖“省时间、自动生成、连续执行、外部连接、运行额度”。
- 商家/API/自动化能力必须有授权和审核，不因订阅等级自动放开。
- 共创用户可以获得试用或临时额度，但不能表述为收益、返利或投资回报。

## 4. 免费与付费边界

免费基础能力：

- 打开页面和单一功能键。
- 基础搜索。
- 基础 AI 对话。
- 简单动态草稿。
- 查看自己的积分、名片、消息和动态。

可能收费的高级能力：

- 多动作语义执行。
- 连续语音修改。
- 图片/视频生成。
- 表单自动生成。
- 小店服务卡批量生成。
- 外部 API 字段映射。
- n8n 自动化执行额度。
- 高级关系推荐和跟进提醒。

## 5. 授权与开通

插件开通必须记录：

- 用户或商家。
- 插件 key。
- 套餐类型。
- 有效期。
- 额度。
- 已用量。
- 状态：试用、启用、暂停、过期、撤销。
- 是否需要外部 API 授权。
- 是否需要后台审核。

## 6. 用量计费事件

每次使用插件都要写入用量事件：

- `plugin_key`
- `user_id`
- `action_type`
- `units`
- `unit_type`
- `billable`
- `status`
- `ref_type`
- `ref_id`
- `created_at`

示例：

```json
{
  "pluginKey": "image_generation",
  "actionType": "generate_cover",
  "units": 1,
  "unitType": "generation",
  "billable": true,
  "status": "confirmed",
  "refType": "dynamic",
  "refId": "post_1"
}
```

## 7. AI 执行前检查

AI 调用收费插件或订阅能力前必须检查：

1. 用户当前订阅档位是否允许该能力。
2. 用户是否已开通对应插件。
3. 插件是否在有效期。
4. 额度是否足够。
5. 是否需要用户确认收费或消耗额度。
6. 是否需要内容审核。
7. 是否需要外部 API 授权。

如果未开通：

```text
这个能力属于高级插件。你可以先预览效果，确认后再开通。
```

如果额度不足：

```text
这个插件额度已用完，可以继续编辑已有内容，或升级/补充额度后再生成。
```

## 8. 前端低调提示

插件入口不放大广告，不破坏华伴 CI。

文案：

```text
高级能力
图文视频生成、表单、小店 API 和自动化可作为插件开通。
```

确认文案：

```text
这次操作会使用插件额度，确认后继续。
```

## 9. 后台要求

后台需要管理：

- 订阅档位。
- 插件目录。
- 用户插件权益。
- 使用记录。
- 额度扣减。
- 试用开关。
- 退款/撤销记录。
- 风险用户限制。
- 插件收入统计。

## 10. 与积分权益的边界

插件收费和积分权益必须分开。

- 插件付费是购买功能使用权或额度。
- 积分是参与和贡献记录。
- 插件购买不自动增加贡献积分。
- 贡献积分不承诺兑换插件、现金、股权、证券或固定收益。
- 可以设计“共创用户试用插件”或“积分任务奖励插件体验券”，但要明确不是收益承诺。
