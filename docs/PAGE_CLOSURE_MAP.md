# 华伴 V1.1 页面闭环作战地图

更新日期：2026-07-28

本文件只解决一个问题：用户从任何入口进入任何页面后，每一个按钮为什么存在、点了去哪、下一步做什么、成功和失败如何处理。

判定原则：

- 页面能打开不等于功能完成。
- 按钮能点不等于流程闭环。
- 弹层只做选择，不承载完整流程。
- 每个页面必须有返回、取消、确认、删除或保存等基本出口。
- 不能成功的功能必须明确显示“待接入”或“失败”，不能假成功。

## 0. 全局导航

| 位置 | 按键 | 作用 | 去向 | 成功状态 | 失败/风险 |
| --- | --- | --- | --- | --- | --- |
| 底部导航 | 首页 | 回到消息和 AI 对话中心 | `homePage` | 首页高亮，消息列表可见 | 不应打开动态或发布 |

| 底部导航 | 动态 | 看其他用户动态 | `nearbyPage` | 动态高亮，动态流可滚动 | 不负责发布 |
| 底部导航 | 我 | 打开个人中心 | `mePage` | 我页高亮 | 身份、积分数据需接口验证 |
| 首页输入框 | 声波 | 直接语音入口 | 当前输入框/语音能力 | 待原生能力接入 | 当前不能假装已发送语音 |
| 首页输入框 | 麦克风 | 语音转文字 | 浏览器识别后执行指令 | 识别成功后进入对应页面 | 浏览器不支持时必须提示 |

## 35. 明日验收顺序建议

1. 发布动态链：动态页右上角 `+` → 来源 → 编辑 → 草稿箱 → 发布失败保留 → 发布成功删除当前草稿。
2. 位置链：对话 `+` → 位置 → 搜索/手动输入 → 完成 → 回对话输入框。
3. 添加朋友链：菜单/通讯录 → 添加朋友 → 扫一扫/手机联系人/当面拉群，各自确定闭环等级。
4. 个人资料链：任何头像 → 个人资料 → 朋友资料/动态/发消息。
5. 积分链：完成动作 → 后端积分流水 → 礼花 → 我页积分权益可查。
