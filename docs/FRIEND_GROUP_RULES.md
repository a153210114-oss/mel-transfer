# 好友分组规则

华伴 V1.1 好友默认按地域关系分为三组。

## 分组

- 当地：同城或同一主要生活圈，例如同在 Melbourne。
- 异地：同一国家但不同城市，例如 Melbourne 与 Sydney。
- 异国：不同国家，例如 Australia 与 China、Singapore、New Zealand。

## 数据字段

`hb_friend_notes.geo_group`

- `local`：当地
- `remote_domestic`：异地
- `overseas`：异国

## 使用位置

- 通讯录分组
- 朋友资料页
- AI 推荐名片排序
- 动态内容推荐
- 城市运营与关系沉淀
